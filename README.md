# AUREVON — Railway

Отдельная копия от 2 ноября 2026. Текущий Beget, локальная версия и PHP-комплект переноса не менялись. Это сайт с 846 товарами и сохранением заявок. Обработчик Telegram подготовлен отдельно в bot/, но ещё не подключён к Telegram. Доставка менеджеру не настроена. См. bot/DEPLOY.md. Скрипт scripts/concierge.mjs выполняет только проверку подключения с --check; не запускайте его как основной сервис.

## Развернуть

1. Создайте приватный GitHub-репозиторий и загрузите СОДЕРЖИМОЕ этой папки в корень. Не загружайте всю рабочую папку Codex, старую базу, .env или токены.
2. Railway → New Project → GitHub repo → нужный репозиторий. Если аккаунт/платёжный план не подготовлен, владелец настраивает его отдельно; комплект сам ничего не покупает.
3. Railway использует Dockerfile: Node.js 24, команда `node cloud.mjs`. Зависимостей npm нет. Если код лежит в подпапке репозитория, укажите её как Root Directory.
4. ДО первого полноценного запуска добавьте постоянный Volume и смонтируйте в `/data`. Переменная `AUREVON_DATA_DIR=/data`. Без volume контейнерная база может потеряться при следующем развёртывании. Используйте один экземпляр сервиса; SQLite-файл нельзя разделять между несколькими экземплярами этим комплектом.
5. Разверните сервис, затем Settings → Networking → Generate Domain. Приложение слушает `0.0.0.0` и порт `PORT`, который предоставляет Railway (по умолчанию 8080). Healthcheck `/api/health` задан в railway.json.
6. Добавьте в Variables `AUREVON_PUBLIC_ORIGIN=https://ВАШ-АДРЕС`, без завершающего слеша. Примените переменные/перезапустите развёртывание. До настройки домена каталог доступен, но сохранение заявок возвращает 503. Запросы с другого Origin блокируются.
7. При необходимости задайте `AUREVON_ADMIN_TOKEN` длинным случайным секретом для защищённого экспорта заявок. Не публикуйте его. Для ограниченного превью поддерживается `AUREVON_PREVIEW_KEY` (32–128 URL-safe символов); ссылка `https://ВАШ-АДРЕС/?preview=КЛЮЧ`. Без ключа сайт открыт.
8. Проверьте HTTPS-главную, `/api/health`, каталог, фото, Wishlist, Cart. Отправьте одну явно тестовую заявку со своим тестовым контактом. Проверьте, что после redeploy запись сохранилась в volume. В обычные логи контакты не выводятся.

## Telegram

Для открытия магазина настройте в BotFather HTTPS-адрес мини-приложения/кнопки меню бота. `AUREVON_BOT_USERNAME` — необязательное имя без @, оно не включает доставку сообщений. Токен бота для сайта не нужен.

Для общения/доставки менеджеру требуется отдельная реализация обработчика, подтверждённый chat ID получателя, настройка секрета и проверка существующего webhook/worker. Не запускайте второй polling-процесс и не удаляйте webhook вслепую. В этом комплекте заявка сохраняется, но не отправляется менеджеру; пользовательский интерфейс сообщает это прямо.

## Хранение и резервные копии

SQLite: `/data/inquiries.sqlite`, содержит контакты. Доступ к volume только у уполномоченных администраторов. Экспорт API `/api/admin/inquiries` требует Bearer admin token. Не помещайте базу в GitHub, архив для публичного скачивания или app/. Резервное копирование/восстановление: scripts/data.mjs; перед использованием изучите его команды. Резервные копии должны храниться отдельно от того же volume.

## Ограничения и проверка

Цен нет; распродажа скрыта до утверждённого прайса. Онлайн-оплаты нет. Видео загружается с внешнего сервера Audemars Piguet, каталог фотографий требует отдельного подтверждения коммерческих прав. Переход на новый адрес не переносит Wishlist/Cart между доменами, так как они в хранилище браузера.

Проверка кода: Node.js 24 → `npm test`. Тесты используют отдельные временные SQLite и вымышленные контакты; Telegram не вызывают. Docker-сборку и работу на Railway надо подтвердить после подключения аккаунта — локальные тесты не являются отчётом облачного запуска.

Официальный старт Railway: https://docs.railway.com/quick-start
